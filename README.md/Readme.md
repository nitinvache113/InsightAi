# InsightAI

## An Explainable AI-Driven Customer Intelligence Platform for Churn Prediction, Customer Segmentation, and Retention Analytics

InsightAI is an explainable customer intelligence platform that combines machine learning, customer segmentation, SHAP-based explainability, and retention analytics to transform customer data into actionable business insights.

## Key Capabilities

- Customer churn prediction
- Customer risk classification
- Customer segmentation
- SHAP-based explainability
- Individual customer risk analysis
- Retention priority identification
- Retention campaign recommendations
- Interactive analytics dashboard
- New customer risk prediction
- Model performance evaluation
